# Finora — Трекер личных финансов

Учебный завершённый веб-проект на Flask по теме «Трекер личных финансов».

## Возможности

- регистрация и вход пользователя;
- безопасное хранение паролей через `generate_password_hash` / `check_password_hash` (salt входит в хеш);
- авторизация через Flask-Login;
- защищённые маршруты с `@login_required`;
- добавление доходов и расходов;
- дата, категория, комментарий и сумма операции;
- автоматический расчёт текущего баланса;
- история операций;
- поиск и фильтрация через GET-параметры `request.args`;
- обработка данных форм через POST `request.form`;
- редактирование профиля и валюты;
- адаптивный интерфейс в розовой минималистичной стилистике;
- декоративные цветы на фоне без внешних UI-библиотек.

## БД

Основные сущности задания:

- `User`- пользователь;
- `Transaction`- финансовая операция;
- `Category`- категория.

Связь `User 1:M Transaction` и `Category 1:M Transaction`.
